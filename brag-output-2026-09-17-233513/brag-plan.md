# Brag Plan: Cortex

## What is this app?

Cortex is a local-first, Git-backed notes system that keeps Markdown, code, repositories, Git history, and agent context in one living graph.

## The angle

Treat the video like a quiet, confident product launch for the moment when a “notes app” stops being a folder of disconnected files. The reveal is specific: open a real project note, expose the attached source module and repository state, then pull back to the graph that explains why the note matters. The product is the relationship between the note and the work around it.

## Hook (first 2-3 seconds)

“Notes are not the context.” appears as a large, calm interruption over a dark Cortex canvas, followed by “Cortex is.” The second line is the handoff into the product UI.

## Key moments (the middle)

- The three-region desktop surface: search/recents/tree on the left, a rendered “Project Spec” note in the center, and context on the right.
- The graph relationship assembles visibly: `project-spec.md` documents the Cortex repository and implements/relates to `src/mcp/server.ts`.
- The app’s invariant lands as three concise promises: Markdown source of truth, rebuildable SQLite index, strict MCP tools.

## Outro / punchline

“Cortex” lands with “Context that stays attached.” The final image holds on the product name and the connected note/code relationship, not a generic CTA.

## User flow worth showing

Choose a vault → open a note → read/edit Markdown → inspect connected code and repository context → open the graph → return to the note with context intact.

## Tone

- Preset: polished
- Creative direction: a quiet product film for the moment notes become infrastructure
- Interpretation: restrained typography, confident holds, dark surfaces, deliberate graph motion, and no hype language. Movement comes from the UI assembling and relationships locking into place.
